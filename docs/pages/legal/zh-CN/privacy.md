# 隐私政策（YAT Desktop Client）

**更新日期：2025 年 10 月 1 日**

本隐私政策适用于**所有用户**，包括使用「邮箱账号密码注册登录」及「Google/GitHub OAuth 授权登录」的用户，覆盖全球各地区，适配各地数据保护法规要求。

## 1. 数据控制者

数据控制主体：alpha pei / YAT Studio
联系邮箱：support@tunnel6.com

## 2. 我们收集的数据

### 2.1 邮箱注册用户（主动收集）

- 用户注册邮箱
- 用户设置的加密登录密码（仅哈希存储，**不保存明文密码**）

### 2.2 OAuth 登录用户（第三方授权获取）

- Google / GitHub 唯一用户 ID
- 授权的公开邮箱地址

### 2.3 系统自动匿名收集

- 软件 License 证书序列号
- 匿名节点设备 ID
- 软件启动上报计数、授权状态日志

**我们绝不收集：真实姓名、地址、手机号、证件信息、支付卡信息。**

## 3. 数据使用目的

您的个人数据仅用于：

1. 账号注册、登录、身份核验、账号安全管理；
2. 签发、管理、校验、吊销软件授权 License；
3. 推送账号通知、授权变更、服务公告、违规提醒；
4. 统计软件授权激活状态，保障服务安全与合规；
5. 处理用户申诉、删除申请、客服事务。

**我们不会未经用户许可发送营销广告邮件。**

## 4. 数据共享第三方

- 身份验证服务：Google、GitHub（OAuth 用户）
- 云服务与安全：Cloudflare、AWS（新加坡托管）
- 支付服务商：Stripe（仅交易处理，不储存个人数据）

所有第三方均具备全球合规数据保护能力。

## 5. 数据留存规则

1. **邮箱、账号标识**：保留至用户主动注销账号；注销后 **30 日内彻底清除个人数据**。
2. **安全审计日志**：最长保留 24 个月，自动过期清理。
3. **匿名统计数据**：无个人标识，可长期留存用于服务优化。

## 6. 用户法定权利

无论您来自哪个地区，您拥有：

- 访问本人数据权利
- 更正错误数据权利
- **账号注销、个人数据删除权（被遗忘权）**
- 撤回数据处理同意权
- 获取个人数据副本权利

您可通过官方联系邮箱随时提交申请，我们将在法定时限内响应。

## 7. 数据安全保护

- 用户密码全程 **bcrypt / 哈希加密存储，无明文**
- 邮箱数据加密存储、最小权限访问
- 平台具备防泄露、防越权、防攻击安全策略
- 如发生合规数据泄露事件，将依法完成监管通报与用户告知

## 8. 跨境数据传输

您的所有数据存储于**新加坡合规服务器**。跨境数据传输均采用合规保护机制，满足各地区数据保护法规的跨境传输标准。

## 9. Cookie 与追踪

仅使用**必要登录会话 Cookie**，无广告追踪、无用户行为追踪。

## 10. 政策更新

本政策可随时修订，修订后页面公示即生效，持续使用平台即视为接受新版本。
