# Privacy Policy (YAT Desktop Client)

**Last Updated: October 1, 2025**

This Privacy Policy applies to **all users**, including users who register/login via **email & password** or **Google/GitHub OAuth**. It covers users worldwide and complies with applicable data protection regulations in each region.

## 1. Data Controller

Controller: alpha pei / YAT Studio
Contact Email: support@tunnel6.com

## 2. Data We Collect

### 2.1 Email Registration Users

- Your registered email address
- Hashed login password (**no plaintext stored**)

### 2.2 OAuth Login Users (Google / GitHub)

- Unique OAuth user ID
- Authorized email address

### 2.3 Automatically Collected Anonymous Data

- License serial number
- Anonymous node device ID
- Software startup report logs and license status records

We **do NOT collect real name, address, phone number, ID documents, or payment card data**.

## 3. Purposes of Data Processing

Your personal data is used strictly for:

1. Account registration, login verification, and account security management;
2. Issuing, verifying, managing, and revoking software licenses;
3. Sending essential service notifications, license updates, and security alerts;
4. Maintaining platform security and compliance;
5. Responding to user inquiries, deletion requests, and support services.

**No marketing emails will be sent without explicit user opt-in.**

## 4. Third-Party Processors

- Identity providers: Google, GitHub
- Cloud & security infrastructure: Cloudflare, AWS (Singapore)
- Payment processor: Stripe (payment-only, no personal data storage)

## 5. Data Retention

- Email and account data: retained until account deletion request. All personal data will be erased within **30 days after deletion**.
- Security audit logs: retained maximum 24 months.
- Fully anonymous statistics may be retained for service optimization.

## 6. User Legal Rights

You have the right to:

- Access your personal data
- Correct inaccurate data
- Request account deletion & personal data erasure
- Withdraw consent
- Receive a copy of your personal data

You may submit requests via our official contact email.

## 7. Data Security

- All passwords are hashed with secure algorithms (no plaintext storage)
- Personal data is encrypted and access-restricted
- The platform maintains security protocols against leakage and attacks
- Legal breach notification procedures are in place

## 8. Cross-border Data Transfer

All data is hosted on secure servers in **Singapore**. Cross-border data transfers comply with applicable data protection regulations in each region.

## 9. Cookies

Only essential session cookies for login functionality. No tracking cookies, no advertising cookies.

## 10. Policy Updates

We may update this Privacy Policy. Updates take effect upon public posting. Continued usage means acceptance of revised terms.
