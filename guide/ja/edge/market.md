# Edge マーケットと共有

> 共有 Edge ノードを購読するか、自分の Edge を他のデバイスと共有します。

---

## 共有 Edge を購読

1. **Edges** を開き、**Marketplace** を選択します。
2. 利用可能なノード、所有者、リージョン、状態を確認します。
3. ユーザーに近い Edge を選びます。
4. **Subscribe** をクリックして確認します。

購読後、Edge は **My Edges** に表示され、トンネル作成時に選択できます。

> 📸 ![Edge snapshot](../../../guide/images/snapshot-edge-market.png) Edge マーケット

## 購読を解除

1. **My Edges** を開きます。
2. 対象の共有 Edge を探します。
3. **Unsubscribe** をクリックします。
4. 確認します。

その Edge を使うトンネルは直ちに停止します。別の Edge に変更するか、再作成してください。

## Edge を共有

共有機能は開発中です。予定されている操作は次のとおりです。

- 購読できるデバイスまたはユーザーの選択
- トラフィックや接続数の上限設定
- 利用統計の確認
- サーバーを再デプロイせずに権限を取り消す

対応までの間は、同じアカウントの複数デバイスで自分の Edge を利用できます。

## 共有 Edge の選び方

| 要素 | 推奨 |
|------|------|
| リージョン | ユーザーやサービスに近いノードを選ぶ |
| 帯域 | 負荷に十分な上限を確認する |
| 可用性 | 安定した稼働履歴があるノードを優先する |
| 信頼性 | 知っている運用者または公式ノードを使う |
