## Edge とは

NAS、データベース、ノート PC 上の開発サーバーはプライベートネットワーク内にあり、外部から直接アクセスできません。 Edge はその隙間を埋めます。公開アドレスを持つマシンで動作し、ローカルの YAT クライアントとの間に mTLS で双方向認証された持続的接続を維持します。外部リクエストはまず Edge に届き、その接続を通じて内部サービスへ渡されます。内部マシンのポートを開いたり、ルーターを変更したりする必要はありません。

```
Edge なし: 訪問者 ✗ -- ルーターがポート転送せず、リクエストが届かない
Edge あり: 訪問者 → Edge（公開入口） → 認証済み接続 → 内部サービス
```

## Edge の役割

| 責務 | 内容 |
|------|------|
| **公開入口** | HTTP/HTTPS、TCP、UDP、WireGuard のポートで待ち受け、受信トラフィックを受け取る |
| **転送** | ドメインまたはポートごとに正しいトンネルへ振り分け、応答も同じ接続で返す |
| **認証と暗号化** | Captain とクライアントの両方で相互認証を行い、ネットワーク位置ではなく識別情報に基づいて信頼する |
| **ドメイン割り当て** | 各トンネルに `abc123.edge.myroxy.dev` のようなホスト名を割り当て、独自ドメインも利用できる |
| **状態報告** | オンライン状態、トンネル一覧、トラフィック統計を報告し、コンソールの健康確認に使う |

## Edge の入手方法

| 種類 | 内容 | 適した場面 |
|------|------|------------|
| **公式ノード** | YAT が複数リージョンで提供し、アカウント登録後に利用できる | 個人利用や多くのチーム |
| **自己ホスト Edge** | 自前の VPS に設置し、帯域、ポート、証明書を専有 | 本番運用や出口を管理したい場合 |
| **共有 Edge** | 他のデバイスや第三者が共有する Edge を購読 | テストや一時的な利用 |

自己ホストと共有ノードは、クライアントの **Edges** ページで管理します。手順は [Edge サーバーをデプロイ](./deploy.md) と [Edge マーケットと共有](./market.md) を参照してください。
