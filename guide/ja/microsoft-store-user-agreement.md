# 🖥️ Microsoft Store ユーザー規約

> Microsoft Store 経由で配布される YAT アプリケーションと、それを利用するユーザーとの法的契約です。

## 📜 規約への同意

Microsoft Store から配布される YAT アプリケーションをダウンロード、インストール、または利用すると、本規約に同意したものとみなされます。同意できない場合は、ダウンロード、インストール、利用を行わないでください。

### 1. ライセンス

YAT は、本規約に従い、個人的かつ非商用の目的でアプリケーションを使用する、限定的で非独占的、譲渡不可、取消可能なライセンスを付与します。

### 2. ユーザーの責任

次の事項に同意します。
- アプリケーションを合法的な目的でのみ使用する
- 改変、リバースエンジニアリング、逆コンパイルをしない
- 再配布またはサブライセンスを行わない
- 適用される法令と規制を遵守する

### 3. データ収集とプライバシー

YAT アプリケーションは次のデータを収集します。
- **必須データ**：デバイス情報（OS バージョン、ハードウェア識別子）、接続状態、トンネル指標
- **任意データ**：明示的な同意に基づく利用統計
- **収集しないデータ**：個人識別情報（PII）、閲覧履歴、コンテンツ

データ収集は Microsoft Store のポリシーと適用されるプライバシー法に従います。

### 4. 知的財産権

YAT アプリケーションに関するすべての権利、権限、利益、および知的財産権は YAT Team に帰属します。本規約は、明示的に記載された範囲を除き、これらの権利を付与しません。

### 5. 責任制限

適用法令で認められる最大限の範囲において、YAT TEAM は明示または黙示のすべての保証を否認します。これには商品性および特定目的への適合性の黙示の保証を含みますが、これらに限定されません。また、アプリケーションの利用から生じる間接的、偶発的、特別、または結果的損害について責任を負いません。

### 6. 終了

本規約に違反した場合、YAT Team はいつでも本規約を終了できます。終了後はアプリケーションの利用を中止し、デバイスからアンインストールしてください。

### 7. 準拠法および管轄

本規約は、法の適用に関する規定を考慮することなく、アメリカ合衆国カリフォルニア州法に準拠します。本規約に起因する法的措置は、カリフォルニア州サンフランシスコ郡にある州裁判所または連邦裁判所に提起します。

### 8. 規約の変更

YAT Team はいつでも本規約を更新できます。最新版はウェブサイトに掲載されます。変更後もアプリケーションを利用し続けた場合、更新版に同意したものとみなされます。
