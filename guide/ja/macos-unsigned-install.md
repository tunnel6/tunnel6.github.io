# macOS インストールガイド（未署名 / 自己署名ビルド）

> YAT の macOS パッケージは現在**Apple の公証（notarization）を受けていません**。初回起動時に Gatekeeper によってブロックされる場合があります。このページでは、ワンクリック修復、Finder での許可、システム設定での許可、ターミナルコマンド、ローカルでの ad-hoc 自己署名まで、すべての解決方法をまとめています。

---

## 🧭 なぜブロックされるのか

現在の macOS ビルドは、有料の Apple Developer ID 証明書で署名されておらず、Apple の公証も受けていません。Gatekeeper はこうしたアプリを既定でブロックします。よく表示されるメッセージは次のとおりです：

| macOS のメッセージ | 実際の意味 |
|-------------------|-----------|
| 「悪質なソフトウェアかどうかを検証できないため、開けません」 | 公証されていないアプリへの通常のブロック |
| 「YAT は壊れているため開けません」 | 未署名ビルドに対する Gatekeeper の標準的なメッセージです。**ファイルが実際に壊れているわけではありません** |
| 「開発元を検証できません」 | 同上。未署名アプリでは想定内の挙動です |

> ⚠️ 安全のために：ダウンロードは **GitHub Releases の公式ページ**からのみ行い、同梱の `SHA256SUMS.txt` でファイルの整合性を確認してから次の手順に進んでください。

---

## ✅ 方法 1：通常のインストール（まずはこれを試す）

1. ダウンロードした `.dmg` をダブルクリックします。
2. **YAT.app** を **Applications** フォルダのアイコンにドラッグします。
3. DMG を取り出し、**Launchpad** または **Applications** から YAT を起動します。
4. ブロックされた場合は、以下の方法を試してください。

> 💡 必ず YAT.app を /Applications に移してから起動してください。DMG ウィンドウから直接実行すると、App Translocation（読み取り専用のランダムなマウント）が発生し、修正が永続化しません。詳しくは下の「App Translocation」のセクションを参照してください。

---

## 🛠 方法 2：DMG 内のワンクリック修復（推奨）

DMG にはワンクリック修復スクリプト `③ fixapp.command`（「初回起動に失敗したらこちら」）が同梱されています：

1. **先に YAT.app を Applications に移動**し、その後スクリプトをデスクトップ（または Applications）にドラッグします。
2. デスクトップ上のスクリプトをダブルクリックします。
3. スクリプトは自動的に次の処理を行います：
   - `YAT.app` からのみ `com.apple.quarantine` フラグを削除（システム設定は変更しません）；
   - YAT を起動；
   - 起動が失敗した場合は、YAT を Gatekeeper の許可リストに追加して再試行；
   - 結果をダイアログで通知。

> ❓ **スクリプトをダブルクリックしても何も起きない？** macOS がスクリプトにも隔離フラグを付けている可能性があります。Finder で `Control` キーを押しながらスクリプトをクリック →「開く」を選択 → ダイアログでもう一度「開く」をクリックしてください。または、スクリプトを先にデスクトップへコピーしてから実行してください（読み取り専用の DMG から直接実行すると App Translocation の制限を受けます）。

---

## 🖱 方法 3：Finder で一度だけ許可（ターミナル不要）

1. **Applications** を開き、`YAT` を見つけます。
2. `Control` キーを押しながらアプリのアイコンをクリックし、**開く** を選択します。
3. 確認ダイアログでもう一度 **開く** をクリックします。

この操作は一度だけ必要で、以後は通常どおりダブルクリックで起動できます。

> ℹ️ macOS 15（Sequoia）以降ではこの入口が厳格化されています。Control-クリックのメニューに「開く」が表示されない場合は、方法 4 を使用してください。

---

## ⚙️ 方法 4：システム設定で許可する

1. 方法 1 で通常どおりインストールし、YAT を一度ダブルクリックしてブロックを発生させます。
2. **システム設定 → プライバシーとセキュリティ** を開きます。
3. 一番下までスクロールし、「YAT はブロックされました」の通知を見つけて、**このまま開く** をクリックします。
4. 管理者パスワードを入力して確認します。

---

## ⌨️ 方法 5：ターミナルコマンド（ワンクリック修復と同等）

ターミナルに慣れているユーザー向け。ワンクリック修復スクリプトの中核と同じ操作です：

```bash
# YAT.app の隔離フラグのみを削除（システム全体の設定は変更しません）
xattr -dr com.apple.quarantine "/Applications/YAT.app"

# 起動
open "/Applications/YAT.app"
```

フラグが削除されたか確認するには：

```bash
xattr -l "/Applications/YAT.app" | grep quarantine
# 出力がなければ削除済みです
```

## ✍️ 方法 6：ローカルでの自己署名（ad-hoc codesign）

**こんなときに使用します**：

- 方法 5 で隔離フラグを削除しても「YAT は壊れているため開けません」と表示され続ける（バンドル内の署名検証に失敗）；
- 企業 / チーム内での配布で、ローカルで一貫した署名状態にしたい；
- パッケージをローカルで改変した（リソースの差し替えなど）ため、元の署名が検証されなくなった。

```bash
# ad-hoc 署名でアプリ全体に再署名（Apple 開発者アカウントは不要）
codesign --force --deep --sign - "/Applications/YAT.app"

# 隔離フラグを削除して起動
xattr -dr com.apple.quarantine "/Applications/YAT.app"
open "/Applications/YAT.app"
```

署名状態の確認：

```bash
codesign --verify --deep --strict "/Applications/YAT.app"
spctl --assess --verbose "/Applications/YAT.app"
```

**注意**：

- `--sign -` は **ad-hoc 署名**を作成します。証明書は不要で、バンドル内部の整合性のみを保証します。**Apple が認めた開発者アイデンティティではありません**。
- YAT に組み込まれている WireGuard 特権ヘルパーと Network Agent デーモンは、ビルド時点で ad-hoc 署名済みです。この操作によりバンドル全体の署名状態が一貫します。
- 正式な企業向け配布では、ad-hoc ではなく Developer ID 署名 + 公証を推奨します。

必要に応じて：YAT を Gatekeeper の許可リストに追加（スクリプトのフォールバック処理と同じ）：

```bash
sudo spctl --add --label "YAT" "/Applications/YAT.app"
```

## 📦 App Translocation：DMG から直接実行してはいけない理由

アプリやスクリプトを**読み取り専用の DMG から直接実行**すると、macOS は DMG をランダムな読み取り専用パス（`/private/var/folders/.../AppTranslocation/<uuid>/d/`）にマウントします：

- 隔離フラグを削除しても、実際に実行されるのは DMG 内の読み取り専用コピーです；
- 次回の起動では再びブロックされ、修正が永続化しません。

**正しいやり方**：

1. `YAT.app` を **Applications** にドラッグし、`/Applications` から実行する；
2. 修復スクリプトも同様に、デスクトップか Applications にコピーしてからダブルクリックする。

## ❓ よくある質問

| 問題 | 対処 |
|------|------|
| 「YAT は壊れているため開けません」と表示される | 未署名アプリの標準的なメッセージであり、実際の破損ではありません。方法 5 または 6 で解決できます |
| 修復スクリプトをダブルクリックしても反応がない | Control-クリック →「開く」→「開く」。またはスクリプトを先にデスクトップへコピー |
| 修復後もブロックされる | `YAT.app` が `/Applications` にあるか（DMG 内ではないか）確認し、方法 4 を使用 |
| ダウンロードの整合性確認方法 | `shasum -a 256 -c SHA256SUMS.txt` |
| アンインストール方法 | `/Applications/YAT.app` をゴミ箱へドラッグ。ユーザーデータは `~/Library/Application Support/YAT` にあります。必要なら一緒に削除してください |

---

## 🔒 セキュリティに関する注意

- このページのすべてのコマンドは **YAT.app のみを対象**とし、Gatekeeper を全体的に無効化したりシステムのセキュリティを弱めたりしません。
- `sudo spctl --master-disable` のようなグローバルなバイパスコマンドは**実行しないでください**。
- ad-hoc 自己署名は Apple のアイデンティティ信頼モデルを変更するものではなく、ローカルでの整合性修復専用です。
- インストール前には、必ず公式 GitHub Releases からダウンロードし、SHA-256 チェックサムを検証してください。
