# ユーザードキュメント構成メモ

> ガイドの構成と執筆方針をまとめた保守用ページです。学習用ではありません。

## 構成

| ブロック | ドキュメント | 目的 |
|----------|--------------|------|
| 入門 | YAT とは、クイックスタート | 製品説明と最初のトンネル作成 |
| 操作 | トンネル、アプリ、ドメイン、トランスポート | クライアントの日常操作 |
| ネットワーク | WireGuard、マルチデバイス | 共同作業と仮想 LAN |
| Edge | デプロイ、管理、リファレンス | 自前ノードの管理 |
| 診断 | DNS、接続、証明書、性能 | よくある問題の解決 |
| 法務 | Microsoft Store 規約 | 配布要件への対応 |

## 執筆ルール

- コマンドはコードブロックで示す
- 製品画面に英語表記がある場合は画面名も英語のままにする
- ファイル名と画像名は翻訳しない
- 内部リンクは同じ言語のドキュメントを指す
- 画像は常に `/guide/images/...` を使う

## 更新手順

1. 英語または簡体字中国語のガイドを更新
2. スペイン語と日本語へ変更を反映
3. 内部リンクと画像パスを確認
4. 英語スクリーンショットの存在を確認
5. 公開前にビルドを実行
