# マルチデバイスとロール

> 同じアカウントで複数デバイスを利用し、リソースごとに異なる権限を付与できます。

## デバイス

クライアントをインストールすると、それぞれがデバイスとして登録されます。コンソールでは名前、状態、ロール、関連リソースを確認できます。

- 識別しやすい名前を付ける
- 使用しなくなったデバイスを削除する
- 登録シークレットをインストール間で共有しない

## ロール

| ロール | 権限 |
|--------|------|
| Owner | アカウントと全リソースを完全に管理 |
| Admin | Edge とトンネルを管理。アカウント所有権はなし |
| Operator | 許可されたトンネルの起動・停止 |
| Viewer | 状態と統計の閲覧のみ |

## トンネルの共有

1. トンネル詳細を開く
2. 共有設定を開く
3. デバイスまたはユーザーを追加
4. 必要最小限のロールを選択
5. 保存する

## Edge の共有

自前 Edge は他のデバイスやユーザーと共有できます。所有者はサーバー管理権限を維持し、購読者は入口として利用できます。

1. **Edges** を開く
2. 対象 Edge を選択
3. 共有先を追加
4. 購読可否または閲覧のみを設定
5. 保存する

## 運用例

### 小規模チーム
所有者が Edge とトンネルを管理し、メンバーには `Operator` を付与します。

### 期限付きプロジェクト
必要なトンネルだけ共有し、終了後に権限を取り消します。

### 複数端末
環境ごとに Edge を分け、ローカル資格情報を端末間で共有しません。

## セキュリティ

- 観測だけで済む場合は `Viewer` を使う
- 運用担当には `Operator` を使う
- デバイス変更後に権限を見直す
- 期限切れのアクセスを削除する
