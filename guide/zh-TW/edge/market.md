# Edge 市場與共享

> 訂閱和管理共享 Edge 伺服器

---

## 訂閱共享 Edge

### 什麼是共享 Edge？

其他使用者可以將自己的 Edge 共享給同一賬號的其他裝置使用。

### 訂閱流程

#### 步驟 1：瀏覽 Edge 市場

1. 點選 **Edges** > **市場**
2. 檢視可訂閱的 Edge 列表

> 📸 ![Edge snapshot](/guide/images/snapshot-edge-market.png) Edge 市場
> 
> 說明：顯示可訂閱的 Edge、訂閱按鈕、所有者資訊

#### 步驟 2：訂閱 Edge

1. 選擇合適的 Edge
2. 點選 **訂閱** 按鈕
3. 確認訂閱

#### 步驟 3：使用 Edge

訂閱成功後：
- ✅ Edge 出現在"我的 Edge"列表
- ✅ 可以建立隧道
- ✅ 可以檢視狀態

### 取消訂閱

1. 在"我的 Edge"列表中找到 Edge
2. 點選 **取消訂閱**
3. 確認取消

> ⚠️ **注意**：
> - 取消訂閱後，該 Edge 上的隧道會停止
> - 需要重新訂閱才能恢復

## Edge 市場

### 市場功能

Edge 市場是共享 Edge 的交易平臺：

- 📦 **釋出 Edge** - 將您的 Edge 共享給他人
- 🔍 **瀏覽 Edge** - 查詢可用的 Edge
- ⭐ **評分系統** - 檢視其他使用者的評價（開發中）
- 📊 **統計資訊** - 檢視 Edge 的效能指標

### 釋出 Edge（開發中）

目前 Edge 共享功能正在開發中，即將支援：

- 設定共享許可權
- 配置使用限制
- 檢視使用統計
