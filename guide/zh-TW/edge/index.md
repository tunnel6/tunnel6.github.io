## 什麼是 Edge

您的 NAS、資料庫、本地開發服務都躲在內網裡，公網訪問不到。Edge 補的就是這一環：它部署在一臺有公網地址的機器上，與您本地的 YAT 客戶端之間保持一條經過 mTLS 雙向認證的長連線。外部訪問先到達 Edge，再順著這條連線交給內網服務 —— 您不用給內網機器開埠，也不用去路由器上做埠轉發。

```
沒有 Edge：  訪問者 ✗ —— 路由器沒有做埠對映，請求進不來
有 Edge：    訪問者 → Edge（公網入口） → 已認證的連線 → 內網服務
```

## Edge 負責什麼

| 職責 | 說明 |
|------|------|
| **對外入口** | 監聽 HTTP/HTTPS、TCP、UDP、WireGuard 等協議埠，接收外部訪問 |
| **流量轉發** | 按域名或埠把請求路由到對應的隧道，回程流量走同一條連線返回 |
| **身份與加密** | 與 Captain 控制面、客戶端之間全程雙向認證，信任基於身份而不是網路位置 |
| **域名分配** | 隧道自動獲得系統分配的域名（如 `abc123.edge.myroxy.dev`），也可以繫結您自己的域名 |
| **狀態上報** | 上報線上狀態、隧道列表和流量統計，控制台據此做健康檢查 |

## Edge 從哪來

| 來源 | 說明 | 適合 |
|------|------|------|
| **官方節點** | YAT 提供的多地域節點，註冊賬號後即可就近接入 | 大多數個人和團隊場景 |
| **自建 Edge** | 部署在您自己的 VPS 上，獨佔頻寬、埠和證書 | 生產環境、要求出口可控 |
| **共享 Edge** | 訂閱您自己其他裝置或他人共享出來的 Edge | 測試、臨時使用 |

自建和共享都在客戶端的 **Edges** 頁面裡管理，具體步驟見 [部署 Edge 伺服器](deploy.md) 與 [Edge 市場與共享](market.md)。
