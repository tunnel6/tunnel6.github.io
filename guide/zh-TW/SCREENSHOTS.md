## 截圖命名規範

建議使用以下命名規範：

```
格式: {文件編號}-{章節編號}-{描述}.png

示例:
02-01-首次啟動.png
02-02-登入頁面.png
03-01-應用選擇.png
04-01-部署對話方塊.png
```

## 截圖工具推薦

### macOS
- **內建**: Shift + Command + 4（區域截圖）
- **推薦**: CleanShot X、Skitch

### Windows
- **內建**: Win + Shift + S（截圖工具）
- **推薦**: Snagit、ShareX

### Linux
- **內建**: gnome-screenshot、flameshot
- **推薦**: Flameshot、Shutter
