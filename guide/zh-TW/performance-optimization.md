# ⚡ 效能最佳化建議指南

> 合理配置通道數量和頻寬限制，可以有效提升系統效能。監控資源使用情況，及時調整配置。

## 📊 效能監控指標

### 關鍵效能指標
- **CPU 使用率**: Edge 節點 CPU 佔用百分比
- **記憶體使用率**: Edge 節點記憶體佔用百分比
- **網路頻寬**: 即時上傳/下載頻寬使用
- **連線數**: 當前活躍連線數量
- **延遲**: 端到端通訊延遲（RTT）

### 監控工具
- YAT 控制台即時監控面板
- `top` / `htop` 系統監控
- `iftop` 網路流量監控
- `iostat` 磁碟 I/O 監控

## 🛠️ 效能最佳化策略

### 1. Edge 節點最佳化

#### 資源配置
```yaml
# config.yaml
performance:
  max_connections: 1000          # 最大連線數
  bandwidth_limit: 100mbps       # 頻寬限制
  keep_alive: 30s                # 連線保活時間
  worker_threads: 4              # 工作執行緒數
```

#### 硬體最佳化
- **CPU**: 推薦 2 核以上，高併發場景推薦 4 核+
- **記憶體**: 推薦 2GB+，每 100 併發連線增加 512MB
- **磁碟**: SSD 硬碟，確保日誌寫入效能
- **網路**: 千兆網路介面，上行頻寬充足

### 2. 隧道配置最佳化

#### 傳輸模式選擇
| 場景 | 推薦模式 | 說明 |
|------|----------|------|
| 區域網內 | P2P Direct | 最低延遲，最高效能 |
| 行動網路 | Relay Mode | 更穩定，相容性更好 |
| 複雜 NAT | Relay Mode | P2P 成功率低 |
| 高安全性 | Relay Mode | 所有流量經過 Edge 節點 |

#### 通道配置
- **通道數量**: 根據業務需求合理配置，避免過多通道導致資源浪費
- **頻寬分配**: 為關鍵業務通道分配更高頻寬優先順序
- **超時設定**: 合理設定連線超時，避免資源佔用

## 🚨 效能問題診斷

### 高 CPU 使用率
- **可能原因**: 
  - 連線數過多
  - 加密計算密集
  - 日誌級別過高
- **解決方案**: 
  - 限制最大連線數
  - 升級硬體配置
  - 調整日誌級別為 WARN 或 ERROR

### 高記憶體使用率
- **可能原因**: 
  - 快取過大
  - 連線洩漏
  - 大檔案傳輸
- **解決方案**: 
  - 調整快取大小配置
  - 檢查連線管理邏輯
  - 啟用流式傳輸處理大檔案
