# Mercado y uso compartido de Edge

> Suscríbete a nodos Edge compartidos o comparte uno de tus dispositivos con otros usuarios.

---

## Suscribirse a un Edge compartido

1. Abre **Edges** y selecciona **Marketplace**.
2. Revisa los nodos disponibles, el propietario, la región y el estado.
3. Elige un Edge cercano a tus usuarios.
4. Pulsa **Subscribe** y confirma.

Después de suscribirte, el nodo aparece en **My Edges** y se puede seleccionar al crear un túnel.

> 📸 ![Edge snapshot](/guide/images/snapshot-edge-market.png) Mercado de Edge

## Cancelar la suscripción

1. Abre **My Edges**.
2. Busca el Edge compartido.
3. Pulsa **Unsubscribe**.
4. Confirma la acción.

Los túneles que usan ese Edge se detienen de inmediato. Edítalos con otro Edge o créalos de nuevo para restaurar el acceso.

## Compartir un Edge

El uso compartido está en desarrollo. El flujo previsto es:

- Elegir qué dispositivos o usuarios pueden suscribirse.
- Establecer límites de tráfico o conexiones.
- Consultar estadísticas de uso.
- Revocar el acceso sin redesplegar el servidor.

Hasta que esté disponible, usa tu propio Edge en varios dispositivos de la misma cuenta.

## Elegir un Edge compartido

| Factor | Recomendación |
|--------|----------------|
| Región | Elige un nodo cercano a tus usuarios o servicios |
| Ancho de banda | Confirma que el límite cubre tu carga |
| Disponibilidad | Prefiere nodos con historial estable |
| Confianza | Usa un operador conocido o un nodo oficial |
