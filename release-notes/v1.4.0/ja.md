# YAT v1.4.0 リリースノート

## ハイライト

- **Linux へのインストールが簡単に：** Ubuntu Snap / deb パッケージ（x64 / arm64）を新規提供。コマンド 1 つでインストールでき、Linux デスクトップユーザーはすぐに使い始められます。
- **インターフェースを刷新：** Linux / Windows のタイトルバーがシステムのスタイルにより馴染むように。全体的な操作体験がよりスムーズに。

## 改善

- **プラットフォーム識別がより正確に：** トンネル接続にデバイスの OS とバージョン情報を自動付与。クロスプラットフォーム連携がより信頼できるように。

## 修正

- 既知の問題を複数修正し、接続とインターフェースがより安定しました。
