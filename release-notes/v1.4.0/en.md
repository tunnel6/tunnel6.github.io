# YAT v1.4.0 Release Notes

## Highlights

- **Easier Linux Installation:** New Ubuntu Snap / deb packages (x64 / arm64) — install with a single command, ready to use out of the box for Linux desktop users.
- **Refreshed Interface:** Title bars on Linux / Windows now blend in with the native system style, for a smoother overall experience.

## Improvements

- **More Accurate Platform Detection:** Tunnel connections now automatically carry device OS and version info, making cross-platform collaboration more reliable.

## Fixes

- Fixed several known issues for more stable connections and UI.
