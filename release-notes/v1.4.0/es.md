# Notas de versión de YAT v1.4.0

## Destacados

- **Instalación más sencilla en Linux**: nuevos paquetes Snap y deb para Ubuntu (x64 / arm64). Se instalan con un comando y quedan listos para usar.
- **Interfaz renovada**: las barras de título de Linux y Windows ahora siguen el estilo nativo del sistema.

## Mejoras

- **Detección de plataforma más precisa**: las conexiones de túnel incluyen el sistema operativo y la versión del dispositivo, lo que mejora la colaboración entre plataformas.

## Correcciones

- Se corrigieron varios problemas conocidos para mejorar la estabilidad de conexiones e interfaz.
