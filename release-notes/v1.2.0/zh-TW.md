# YAT 桌面用戶端 v1.2.0

## 更新內容

### 組網 — WireGuard 私有網路

可在 YAT 中直接建立和管理基於 WireGuard 的私有網路，將多部裝置納入同一張網，自動分配子網路位址，並即時監控鏈路健康狀態。

- **建立與管理網路** — 選擇協調 Edge 節點、定義子網路（如 `10.24.0.0/24`），並按需選擇中繼模式（停用 / 可選 / 強制）。
- **裝置成員管理** — 在詳情頁檢視已加入裝置、新增或移除成員、修改主機名稱和分配 IP。
- **鏈路狀態與診斷** — 檢視 Peer 會話狀態（收集 → 打洞 → 已連線）、鏈路類型（直連 / 中繼）以及端點觀測資訊，快速排查連通性問題。
- **本機設定預覽** — 在寫入本機 WireGuard 配接器前預覽產生的設定，支援一鍵同步。
- **即時健康狀態** — 網路卡片展示線上成員數、活躍鏈路數，並透過健康橫幅（健康 / 部分 / 離線 / 異常）一目瞭然。
