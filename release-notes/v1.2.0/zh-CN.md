# YAT 桌面客户端 v1.2.0

## 更新内容

### 组网 — WireGuard 私有网络

可在 YAT 中直接创建和管理基于 WireGuard 的私有网络，将多台设备纳入同一张网，自动分配子网地址，并实时监控链路健康状态。

- **创建与管理网络** — 选择协调 Edge 节点、定义子网（如 `10.24.0.0/24`），并按需选择中继模式（禁用 / 可选 / 强制）。
- **设备成员管理** — 在详情页查看已加入设备、添加或移除成员、修改主机名和分配 IP。
- **链路状态与诊断** — 查看 Peer 会话状态（收集 → 打洞 → 已连接）、链路类型（直连 / 中继）以及端点观测信息，快速排查连通性问题。
- **本地配置预览** — 在写入本地 WireGuard 适配器前预览生成的配置，支持一键同步。
- **实时健康状态** — 网络卡片展示在线成员数、活跃链路数，并通过健康横幅（健康 / 部分 / 离线 / 异常）一目了然。
