# YAT デスクトップ v1.2.0

## 新機能

### ネットワーク構築 — WireGuard プライベートネットワーク

YAT 内で WireGuard ベースのプライベートネットワークを直接作成・管理できるようになりました。複数のデバイスを一つのネットワークに接続し、サブネットアドレスの自動割り当てとリアルタイムのリンク状態監視が可能です。

- **ネットワークの作成と管理** — コーディネーター Edge ノードの選択、サブネット（例: `10.24.0.0/24`）の定義、リレーモード（無効 / オプション / 強制）の切り替えが可能。
- **デバイスメンバー管理** — 詳細ページで参加済みデバイスの確認、デバイスの追加・削除、ホスト名の変更、IP アドレスの編集が行えます。
- **リンク状態と診断** — ピアセッションの状態（収集 → パンチ → 接続済み）、パス種別（ダイレクト / リレー）、エンドポイント観測情報を確認し、接続問題を迅速に排查。
- **ローカル設定プレビュー** — ローカル WireGuard アダプターに書き込む前に生成された設定をプレビュー、ワンクリックで同期可能。
- **リアルタイムヘルスステータス** — ネットワークカードにオンラインメンバー数、アクティブリンク数、ヘルスバナー（正常 / 一部 / オフライン / エラー）を一覧表示。

### バグ修正

- 簡体字中国語以外のロケールで、静的ファイルサービスパネルに翻訳フォールバック警告が表示される問題を修正。
- その他の安定性向上とパフォーマンス最適化。
