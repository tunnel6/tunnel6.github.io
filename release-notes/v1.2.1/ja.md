# YAT デスクトップ v1.2.1

## 新機能

### ✨ 新機能

- **ネットワークの CLI 共有** — ワンクリックで共有パッケージをエクスポート。Linux CLI が即座にネットワークに参加。デバイスごとにサインインする苦痛とおさらば 🎉
- **WireGuard ポート自動リトライ** — デフォルトポートが使用中？大丈夫、自動的に次のポートを見つけます。ポート競合？そんな言葉は知りません。

### 🎨 操作性の改善

- スケルトン画面、ローディング状態、ダークモードタイトルバー…总之 UI がよりスムーズに。あるべき場所にアニメーションが揃いました ✨
- ネットワーク詳細ヘッダーがダイエット成功。ボタンたちがアイコンで語ることを覚えました 💪

### 🛡️ 安定性の改善

- ネットワークリストがもう「消える手品」を演じません（Edge オフライン時のキャッシュ保護が稼働中）
- ネットワーク接続速度の向上、WireGuard ハンドシェイクの信頼性向上
- 「俺の環境では動いてたんだけど」系のバグをいくつか駆除 🫠

### 📜 コンプライアンス

- EULA とプライバシーポリシーが中国語・英語・日本語・繁体字中国語で揃いました。法務もようやく満足 ⚖️
