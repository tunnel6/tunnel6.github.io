# YAT Desktop v1.2.1

## What's New

### New Features

- **Network Share to CLI** — export a share package from the network detail page. The Linux CLI imports it to join the same WireGuard network, eliminating per-device sign-in.
- **WireGuard Port Auto-Retry** — when the default listen port is occupied, the client automatically tries the next available port, removing the need for manual conflict resolution.

### Experience Improvements

- Added sidebar view-switch skeleton screens, network leave loading states, Windows native title bar dark mode support, and other UI refinements for smoother page transitions.
- Redesigned the network detail header with icon-style action buttons for a cleaner interface.

### Stability Improvements

- Fixed network list data unexpectedly disappearing when Edge goes offline.
- Improved networking connection speed with more reliable WireGuard handshakes.
- Resolved several network state synchronization issues for overall better stability.

### Legal Compliance

- Added EULA and Privacy Policy documents in Chinese, English, Japanese, and Traditional Chinese.
