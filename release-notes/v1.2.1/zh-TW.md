# YAT 桌面用戶端 v1.2.1

## 更新內容

### ✨ 新功能

- **網路分享到 CLI** — 一鍵匯出分享包，Linux CLI 匯入即可入網。告別逐台裝置登入的折磨 🎉
- **WireGuard 連接埠自動重試** — 預設連接埠被佔？沒問題，它自己會找下一個。連接埠衝突？不存在的。

### 🎨 體驗最佳化

- 骨架螢幕、Loading 狀態、暗色模式標題欄……總之 UI 更滑順了，該有動畫的地方都有了 ✨
- 網路詳情頁頭部瘦身成功，按鈕們學會了用圖示說話 💪

### 🛡️ 穩定性改進

- 網路清單不再玩「消失魔術」了（Edge 離線時快取保護已上線）
- 組網連線速度提升，WireGuard 握手更可靠
- 修復了若干「在我電腦上明明好好的」問題 🫠

### 📜 合規文件

- EULA 和隱私政策已就位，覆蓋中/英/日/繁中四語。法務終於滿意了 ⚖️
