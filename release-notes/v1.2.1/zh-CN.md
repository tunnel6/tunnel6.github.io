# YAT 桌面客户端 v1.2.1

## 更新内容

### 新功能

- **网络分享到 CLI** — 支持从网络详情页导出分享包，Linux CLI 导入后即可加入同一 WireGuard 网络，无需逐设备登录。
- **WireGuard 监听端口自动重试** — 当默认端口被占用时，客户端自动尝试下一个可用端口，无需手动处理冲突。

### 体验优化

- 新增 Sidebar 视图切换骨架屏、离网 Loading 状态、Windows 原生标题栏暗色模式适配等 UI 改进，页面切换更加流畅。
- 网络详情页头部操作区重构，按钮改为图标风格，界面更简洁。

### 稳定性改进

- 修复网络列表在 Edge 离线时数据意外消失的问题。
- 提升组网连接速度，WireGuard 握手更加可靠。
- 修复若干网络状态同步异常，整体稳定性提升。

### 合规文档

- 新增 EULA 和隐私政策文档，覆盖中文、英文、日文、繁体中文。
