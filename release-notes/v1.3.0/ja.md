# YAT v1.3.0 リリースノート

## ハイライト

- **招待コードで参加：** ネットワーク招待トークン機能を追加。招待コードでプライベートネットワークに参加でき、デバイスごとのフルセットアップが不要に。エクスポートされた招待コードは、純粋な Linux 実装の [yat-fe-linux](https://github.com/tunnel6/yat-fe-linux) の yat-cli デーモンプロセスに追加して、ネットワーク参加を完了できます。
- **リンク状態が一目瞭然：** メンバーリストにリンク健全性の段階検出を統合。直接接続 / リレー / オフラインが明確に区別でき、現在のデバイスはハイライト表示＆優先ソート。
- **パス制御：** ピアパスオーバーライドと共有パスネゴシエーションに対応。直接接続とリレーを手動で切り替え可能、パス切替時のエラーメッセージも改善。
- **ピア詳細の強化：** メンバー情報ダイアログをセクション分割レイアウトに再設計。観測エンドポイント、ハンドシェイク統計などの接続診断データを追加。
- **ネットワークリスト表示：** リスト表示モードを追加、ネットワーク参加操作がより直感的に。

## 改善

- **接続状態がリアルタイムに：** Edge グローバル状態監視 + リンク健全性イベント駆動で、ポーリングによる推測を廃止。
- **インタラクションの磨き上げ：** パス切替の誤操作防止、オフライン猶予期間によるデバウンス、状態アニメーションの軽量化、エラーメッセージの多言語対応。
- **開発体験：** 拡張機能のインクリメンタルビルド、ログパスのワンクリックコピー。

## 修正

- 並行処理の競合やデータ衝突による接続不安定の問題を修正。
- アカウント切替やメンバー追加/削除後のキャッシュ・設定残留による状態異常を修正。
- リレーマッチングやパス復旧時の接続断の問題を修正。
- Windows トレイアイコン残留や UI 状態の非同期など、クロスプラットフォーム互換性の問題を修正。
