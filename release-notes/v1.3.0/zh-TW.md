# YAT v1.3.0 更新說明

## 亮點

- **邀請碼入網：** 新增網路邀請令牌機制，透過邀請碼即可加入私有網路，無需逐裝置走完整流程。匯出的邀請碼可新增至 [yat-fe-linux](https://github.com/tunnel6/yat-fe-linux) 純 Linux 實現的 yat-cli daemon 程序中完成組網。
- **鏈路狀態一目了然：** 成員列表整合鏈路健康分級偵測，直連 / 中繼 / 離線狀態清晰可辨，目前裝置高亮標識並優先排序。
- **路徑控制：** 支援對等體路徑覆蓋與共享路徑協商，可手動指定連線走直連還是中繼，路徑切換錯誤提示更友善。
- **對等體詳情升級：** 成員資訊彈窗重構為分區佈局，新增觀察端點、握手統計等連線診斷資料。
- **網路列表檢視：** 新增列表檢視模式，加入網路操作更直觀。

## 改進

- **連線狀態更即時：** Edge 全域狀態監控 + 鏈路健康事件驅動，網路狀態不再靠輪詢猜測。
- **互動細節打磨：** 路徑切換防誤觸、離線寬限期防抖、狀態動畫輕量化、錯誤提示多語言。
- **開發體驗：** 擴充增量建置、日誌路徑一鍵複製。

## 修復

- 修復多處並發競態與資料衝突導致的連線不穩定問題。
- 修復帳號切換、成員增刪後快取/設定殘留引發的狀態異常。
- 修復中繼匹配、路徑恢復等場景下的連線中斷問題。
- 修復 Windows 托盤殘留、介面狀態不同步等跨平台相容問題。
