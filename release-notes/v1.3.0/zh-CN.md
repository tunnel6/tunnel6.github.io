# YAT v1.3.0 更新说明

## 亮点

- **邀请码入网：** 新增网络邀请令牌机制，通过邀请码即可加入私有网络，无需逐设备走完整流程。导出的邀请码可添加到 [yat-fe-linux](https://github.com/tunnel6/yat-fe-linux) Linux daemon 进程中完成组网。
- **链路状态一目了然：** 成员列表整合链路健康分级检测，直连 / 中继 / 离线状态清晰可辨，当前设备高亮标识并优先排序。
- **路径控制：** 支持对等体路径覆盖与共享路径协商，可手动指定连接走直连还是中继，路径切换错误提示更友好。
- **对等体详情升级：** 成员信息弹窗重构为分区布局，新增观察端点、握手统计等连接诊断数据。
- **网络列表视图：** 新增列表视图模式，加入网络操作更直观。

## 改进

- **连接状态更实时：** Edge 全局状态监控 + 链路健康事件驱动，网络状态不再靠轮询猜测。
- **交互细节打磨：** 路径切换防误触、离线宽限期防抖、状态动画轻量化、错误提示多语言。
- **开发体验：** 扩展增量构建、日志路径一键复制。

## 修复

- 修复多处并发竞态与数据冲突导致的连接不稳定问题。
- 修复账号切换、成员增删后缓存/配置残留引发的状态异常。
- 修复中继匹配、路径恢复等场景下的连接中断问题。
- 修复 Windows 托盘残留、界面状态不同步等跨平台兼容问题。
