# YAT デスクトップ v1.2.1-native

## 更新内容

このリリースは大きなアーキテクチャの節目です。**YAT Desktop のネットワーク層をネイティブコード（Rust / Go）で全面的に書き直し**、以前の純粋な Node.js 実装を置き換えました。コアのネットワークロジックは事前ビルドされたネイティブバイナリとして提供され、パフォーマンス、安定性、プラットフォーム間の一貫性が大きく向上しています。

### なぜネイティブ化したのか

以前の Node.js ベースのネットワーク層には、課題が積み上がっていました。プラットフォームごとの差異（とくに Windows の WinTUN と Named Pipe）、低レイヤーなネットワーク操作への制御の難しさ、そして再接続時に安定した WireGuard セッションを維持しにくい点です。ネイティブコードへの移行により、OS レベルの API を直接扱い、決定論的な並行モデルを得て、各プラットフォームで密結合した helper + agent 構成を提供できます。

### アーキテクチャの概要

- **Network Agent（Rust）** — 軽量な常駐ネイティブプロセス。WireGuard インターフェース管理、P2P トンネル確立、Peer ライフサイクル管理を担当します。プラットフォーム慣行に従い独立プロセスとして動作し（macOS / Windows は daemon、Linux は systemd service）、IPC 経由で Electron フロントエンドと通信します。
- **Helper Daemon** — macOS と Windows の特権 Helper。アダプターの作成と破棄を担い、管理者権限が必要な操作をメインアプリケーションから分離します。
- **NAPI Bridge** — 軽量な Node.js ネイティブアドオン。Electron と Agent を橋渡しし、フロントエンドの統合範囲を小さく安定に保ちます。

### 主なメリット

- **安定性** — ネイティブの並行モデルにより、以前は Session リークや Peer 状態の揺れを引き起こしていた非同期のタイミング問題を解消しました。
- **パフォーマンス** — WireGuard ハンドシェイクと P2P パスの確立が明確に高速化しました。Windows ではとくに顕著です。
- **クロスプラットフォームの一貫性** — macOS、Windows、Linux が同じコアネットワークロジックを共有し、プラットフォーム固有の不具合が減りました。
- **保守性** — フロントエンドとネットワーク層のプロセス境界が明確になり、それぞれを独立して進化させやすくなりました。

### このリリースに含まれるもの

- マルチアーキテクチャのネイティブビルドパイプライン（macOS x64 / ARM64、Windows x64）
- Windows 特権 Helper daemon の自動起動
- ネットワークへの並行参加処理を逐次化
- Agent による Edge 接続ライフサイクル管理と遅延接続モデル
- TCP / UDP の再接続と復旧ロジックを改善
- 拡張機能のインクリメンタルビルド対応
